# Svorrent v1.0.1

This release updates the desktop packages to the current Downloads, playback-readiness, and network UI.

## Changes since v1.0.0

- **Playback Readiness & Estimated Time to Play:** Hovering over the Play button now displays the calculated estimated time to stream smoothly without buffering, backed by dynamic buffer evaluation and throughput EMA smoothing.
- **Harmonized Network Telemetry:** Interface upload speed tracking now attributes outgoing torrent traffic accurately, and total uploaded bytes are reported on the Networks dashboard and APIs.
- **Downloads Manager Polish:** Primary video filename display, readable progress bar, clear Pause/Play controls, buffering indicators, and fixed negative progress edge-cases.
- **Swarm & Peer View Improvements:** Resolved peer table column squeeze and IPv6 address overflow; fixed internal scrolling freeze; dynamically hides "All interfaces" pill when only 1 active connection exists.
- **Core Stability:** Windows startup crash fix, download recovery improvements, local API/path hardening, and iOS hotspot UDP heartbeat keep-alive.
- **Autonomous Android USB Tethering Engine:** Persistent session management ensuring uninterrupted DHCP negotiation and dual-network bonding across Android and Samsung devices.

## Compatibility and verification

- Windows packages target x64. The macOS DMG targets Apple Silicon (arm64) only; it is not a universal/Intel build.
- Node.js 18 or newer is required and is not bundled. The macOS app is unsigned and not notarized.
- Frontend and backend tests passed. The DMG checksum and portable ZIP integrity were verified. Windows binaries were cross-compiled on macOS, not runtime-tested on Windows.
