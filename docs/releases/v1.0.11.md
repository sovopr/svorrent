# Svorrent v1.0.11

This release introduces the persistent download history engine, adds in-search downloaded badges with one-click re-download support, integrates autonomous USB tethering DHCP and RNDIS recovery, adds cellular keepalive probes for idle tether connections, and expands interface classification for VPN and network tunnels.

## Changes since v1.0.8

- **Persistent Download History Engine:** Implemented `DownloadHistory` (`backend/lib/history.js`), persisting completed downloads indefinitely in `~/.svorrent/download-history.json` across app restarts and file deletions.
- **Search Downloaded Status & Re-Download Action:** Search results automatically tag previously downloaded releases with a dedicated "Downloaded" badge. Action buttons adapt to "Download again" with one-click restoration using historical magnet URIs and info hashes.
- **Autonomous USB Tethering Watchdog:** Added self-healing recovery for link-local and unassigned cellular adapters (`feth0`), re-enabling USB RNDIS endpoints and preventing CPU spin conditions.
- **Cellular Keepalive Heartbeat:** Added background DNS probe signals for idle cellular tether connections to prevent mobile carrier timeouts during low-throughput periods.
- **VPN and Tunnel Interface Classification:** Expanded interface discovery to identify WireGuard, Tailscale, OpenVPN, IPsec, and virtual tunnel interfaces (`utun`, `tun`, `tap`) with dedicated badges in the Networks dashboard.
- **Safe Path Traversal Protection:** Hardened disk deletion routines with strict parent folder boundary checks, preventing directory escapes during cleanup operations.
