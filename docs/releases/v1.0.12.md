# Svorrent v1.0.12

This release delivers dedicated Homepage navigation and multi-source trending discovery, inline quality and release-tag search filters, manual file deletion reconciliation, resilient in-app updater recovery, and full desktop feature parity across the native Android client.

## Changes since v1.0.11

### Desktop & Core Engine

- **Dedicated Homepage & Trending Discovery (`backend/lib/indexer.js`, `frontend/src/DiscoverPage.jsx`, `frontend/src/App.jsx`):**
  - Promoted the trending spotlight and release feed to a top-level **Homepage** tab; clicking **Homepage** or the **svorrent** brand logo navigates directly to the discovery feed.
  - Added multi-source consensus aggregation across `extto.org`, Knaben, The Pirate Bay, EZTV, and Nyaa with **Movies**, **TV**, and **Anime** categories across **Day (`1D`)**, **Week (`7D`)**, and **Month (`30D`)** timeframes, IMDb/Apple/AniList artwork lookup, and deferred magnet resolution.
- **Inline Search Quality & Tag Filters (`frontend/src/SearchPage.jsx`, `frontend/src/lib.js`):**
  - Added instant resolution pills (`All`, `4K`, `1080p`, `720p`, `SD`), release tag filters (`Remux`, `BluRay`, `WEB-DL`, `HDR`, `Dolby Vision`, `HEVC`), provider filters, relative age pills, and **Reset filters** across both **Homepage** and **Search**, backed by federated **Knaben** search integration (`backend/lib/search.js`).
- **Manual Disk Deletion Reconciliation (`backend/lib/reconcile.js`, `backend/server.js`):**
  - Detects when completed or downloaded payload files are deleted externally (Finder, Windows Explorer, or terminal), immediately closes open WebTorrent file descriptors so disk space is reclaimed without requiring an in-app delete, removes the stale queue entry so it does not re-download, and preserves the historical **Downloaded** badge.
  - Guards disconnected download volumes and unstarted metadata-pending magnets from accidental removal.
- **Resilient In-App Updater & Version Resolution (`backend/lib/updater.js`, `backend/server.js`, `frontend/src/NetworksPage.jsx`, `scripts/build-dmg.sh`):**
  - Removed the stale `'1.0.5'` version fallback and added `build-info.json` + package version synchronization during DMG packaging.
  - Fixed ESM `__dirname` handling in `persistCurrentCommit`, automatically recreated missing updater cache directories during `downloadUpdate` and `integrateRepoCommit`, reset stalled download progress on failures (no more stuck `10%` states), and initialized the **Application** card with `Checking update status…` before first telemetry load.

### Android Client (`android/`)

- **Full Desktop Feature Parity on Android:**
  - Added curated **Homepage** (`HomepageScreen.kt`, `DiscoverRepository.kt`) with trending Movies/TV/Anime carousels, poster spotlight cards, timeframe toggles, multi-source consensus ranking, allowlisted HTTPS artwork validation, and deferred `extto.org` magnet resolution (`SearchRepository.kt`).
  - Integrated **Knaben** search indexer alongside TPB, BitSearch, Torrents.csv, and Nyaa plus inline resolution/tag/source filter chips (`Models.kt`, `MainActivity.kt`).
  - Added persistent `DownloadHistoryManager.kt` displaying **Downloaded** badges and **Download again** actions across Homepage and Search.
  - Added `ReconcileHelper.kt` and runtime reconciliation in `SvorrentEngine.kt` so externally deleted files release native `libtorrent4j` handles and disk space immediately without re-downloading.
  - Hardened `AutoUpdater.kt` with concurrent download guards, cache directory creation, and clean error progress resets, and added JVM unit tests in `SvorrentFeaturesTest.kt`.
