# Svorrent v1.0.8

This release introduces the federated multi-source scraper search engine, eliminates the 40-item search cap with responsive pagination controls, resolves 22 security advisories, introduces a responsive symmetrical Networks interface, bundles standalone Node.js runtimes for zero-dependency desktop execution, and equips desktop launchers with startup daemon verification and auto-termination.

## Changes since v1.0.7

- **Federated Multi-Source Scraper Engine:** Replaced the legacy single-provider scraper with a concurrent federated engine querying BitSearch (with multi-page HTML scraper pagination), The Pirate Bay (apibay.org API), Torrents.csv, and Nyaa RSS.
- **Un-Capped Search Results with Interactive Pagination:** Eliminated the 40-result hard cap. Searches now return hundreds of verified results with pagination controls (25, 50, 100 per page) and windowed page selectors.
- **CVE Reduction & Zero-Dependency Scraper:** Removed the deprecated `torrent-search-api` package, eliminating 22 inherited CVEs. Built native zero-dependency HTTPS scrapers with single-pass entity decoding and loop-based tag stripping.
- **Swarm Integer Sanitization:** Implemented 64-bit overflow masking and underflow clamping to eliminate absurd seed/leech counts caused by malformed tracker protocol payloads.
- **Responsive Networks Dashboard:** Overhauled the Networks tab layout with a 2x2 symmetrical quadrant KPI card grid across all viewport widths. Added responsive column priority to the interfaces table, displaying IP and adapter type as an inline subline on mobile screens to preserve live speed meters and routing toggles without horizontal clipping.
- **Self-Healing Desktop Launchers:** Native macOS (`launcher_mac.m`) and Windows (`launcher.c`) launchers now verify `/api/updater/status` against `build-info.json` before reusing port 3001. If a stale or mismatched background process from an older build is detected, the launcher automatically force-terminates it and launches the fresh bundled backend.
- **Bundled Standalone Node.js Runtime:** Application packages for macOS and Windows now bundle an official standalone Node.js runtime, allowing users to run Svorrent without installing Node.js separately.
- **Guaranteed In-Memory Process Termination:** Resolved the macOS `.app` bundle path resolution bug and enforced unconditional process exit timeouts upon update installation across all platforms.
